# Naples Management PWA

Installable web app for Naples Management.

## Modules
- Receipts
- Payments
- Admissions
- Reception 1.8

Each module opens the corresponding live Google Drive / Google Sheets resource.

## Security
On first launch, the app asks the user to create a 4–8 digit PIN. The PIN is stored only on that browser/device using localStorage. Google account permissions continue to control access to the actual Sheets.

## Install on Android
1. Open the GitHub Pages URL in Chrome.
2. Unlock the app.
3. Tap **Install App**, or use Chrome menu → **Add to Home screen / Install app**.
